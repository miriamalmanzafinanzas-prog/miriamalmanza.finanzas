Miriam Finanzas

Landing page estática para la marca personal Miriam Finanzas. No usa frameworks ni compilación: funciona directo en GitHub Pages.

Archivos
index.html   → diseño, estilos y funcionamiento (no hace falta editarlo)
config.js    → TODO el contenido editable
assets/      → tus fotos
Fotos (carpeta assets/)
Archivo	Dónde se usa	Tamaño sugerido
miriam-principal.jpg	Portada	880 × 1100 px (vertical)
miriam-sobre-mi.jpg	Sección "Sobre mí"	880 × 1100 px (vertical)
favicon.png (opcional)	Icono de la pestaña	64 × 64 px

Reemplaza los archivos conservando el nombre, o cambia las rutas en config.js → imagenes. Si una foto falta, la página muestra un fondo de color en lugar de una imagen rota.

Qué cambiar en config.js
Textos: edita lo que está entre comillas "...". No borres comillas ni comas.
Colores: sección colores.
Enlaces, redes, correo y teléfono: sección enlaces.
Servicios y seguros: lista servicios.
Preguntas frecuentes: sección faq.
Ocultar una sección: visible: false.
Datos de "Sobre mí" (experiencia, certificaciones): descomenta los ejemplos en sobreMi.datos.
Apagar animaciones: animaciones.activadas: false.
Publicar en GitHub Pages
Crea un repositorio en GitHub.
Sube index.html, config.js y la carpeta assets/ a la raíz.
Ve a Settings → Pages.
En Build and deployment elige Deploy from a branch, rama main, carpeta / (root), y guarda.
En uno o dos minutos el sitio estará en https://tuusuario.github.io/nombre-del-repositorio/.
Probar en tu computadora

Abre index.html con doble clic. Para cambios, edita config.js, guarda y recarga el navegador (Ctrl + F5 si no se ve el cambio).

Nota importante

La información del sitio es general y educativa. No incluye promesas de rendimientos ni recomendaciones personalizadas. Evita agregar datos que no puedas comprobar (certificaciones, años de experiencia, cédulas).
